# Together AI

Status: implemented

## Offer boundary

[Shared ownership rules](../commercial-topology.md#offers-and-dimensions) govern this provider.

Standard and the documented discounted Batch audio operation share the public Serverless usage relationship. Execution and endpoint geography qualify rates; Batch keeps successful-result-item accounting and never inherits synchronous source paths. Preserve exact source operation evidence in context mappings. Dedicated inference, commitments, unproved Batch prices and estimated media quotes are not promoted into offers.

The source authorities and evidence limits below remain authoritative. Adapter keys such as
`sync`, `batch`, `usage`, and operation/model-specific labels describe extraction contexts;
`source_contexts` binds them to the published relationship and its conditions. They are not
additional user-selectable agreements. Migration preserves monetary facts, conditional accounting,
source revisions and independently charged subjects.

The [Serverless model catalog](https://docs.together.ai/docs/serverless/models) owns public
admission. Accept exact API model strings from the model tables. When Chat and Vision list
the same ID, retain one model and add image input from Vision. The dedicated catalog is a
separate product. The catalog is non-exhaustive and describes the shared Serverless API.
The organization column supplies the publisher label.

The [lifecycle guide](https://docs.together.ai/docs/deprecations) qualifies current catalog
rows by exact API ID. A scheduled removal records deprecation, the announced date and an
explicit replacement when supplied. A matching entry in the completed Inference removal
history suppresses current routes and pricing while retaining the retired model record.
Fine-tuning removals are outside this Serverless scope. Active redirects add exact aliases
only when the target is admitted and the old identifier has no separate catalog row.
The [Messages](https://docs.together.ai/docs/inference/messages-api) and
[Responses](https://docs.together.ai/docs/inference/responses-api) support tables add routes
only for exact Serverless IDs with a positive support marker.

The optional authenticated `GET /v1/models` uses `TOGETHER_API_KEY`. Treat it as a scoped
inventory. It can fill a license label or a missing token context on an exact public match.
Context enrichment requires a token-based model type and a value greater than one. Media
inventory values do not establish a token context window. Account-only
entries and inventory pricing cannot define a public model or rate. A missing credential or
failed inventory leaves the public source independently usable.

The optional [Model Library](https://www.together.ai/models) overlay follows its bounded
public pagination and fetches Serverless cards for exact catalog IDs. A card's displayed
endpoint must repeat that ID before it supplies a description or context-window label.
Reasoning tags and labeled modalities from the library and matched cards are recorded as
positive metadata. Rounded context
labels stay separate from exact token limits. The optional
[changelog](https://docs.together.ai/docs/changelog) supplies release dates from dated
Serverless launch entries for exact catalog IDs.

The public tables supply exact USD token rates and the listed audio duration and character
rates. Cached input is an independent quantity where Together publishes a cached rate.
US-only token pricing joins a unique exact catalog label in the dedicated US table and
keeps its endpoint selector separate from the standard endpoint. Exact API IDs bind these
offers through the shared inference-price lookup.

Image estimates, step-dependent megapixel rates and video examples remain raw when the
published headline does not establish a complete executable billing rule. The
[Seedance 2.0 card](https://www.together.ai/models/seedance-2-0) identifies the structured
catalog's per-video quote as an estimate. The dated per-second launch quote describes a
specific configuration and does not supply a current tariff across supported configurations.

The [Batch overview](https://docs.together.ai/docs/inference/batch/overview) joins an exact
discounted audio ID to its Serverless per-minute rate. The standard and discounted rates
are extracted with separate source operation selectors and assembled as `usage` and `batch` extraction contexts, then combined into one relationship offer. Their canonical selection claims describe `request` and `batch` execution; mechanism
operation predicates are removed from rate applicability and retained in raw evidence. Endpoint
geography remains a price condition. Batch bills successful result items and the discount
excludes dedicated inference. The guide also establishes the audio translation route where
it names the model. Other Batch terms, provisioned throughput, dedicated capacity and
negotiated account terms are outside this source's commercial scope.
